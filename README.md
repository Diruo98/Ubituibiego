# Verso di te — viaggio spaziale interattivo 🌌

Sito romantico per GitHub Pages, responsive e senza dipendenze di build. Include un cielo stellato animato, pianeti cliccabili con ricordi, una costellazione interattiva e una dedica finale.

## Personalizza il sito

Apri `script.js` e modifica la sezione `CONFIG`:
- `initials`: le iniziali di voi due;
- `signature`: il nome o soprannome con cui vuoi firmarti;
- `memories`: titolo e testo dei cinque ricordi.

Puoi personalizzare testi e titoli anche in `index.html`. I ricordi sono testi segnaposto: sostituiscili con esperienze vostre. Per aggiungere foto reali, si può estendere la finestra dei ricordi e caricare le immagini nella repository.

## Pubblica con GitHub Pages

1. Crea un repository su https://github.com, per esempio `verso-di-te`.
2. Carica `index.html`, `style.css`, `script.js` e `README.md` nella radice del repository.
3. Vai su **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, seleziona `main` e `/ (root)`, quindi salva.
5. Quando GitHub pubblica il sito, copia l'URL Pages e usalo per generare il QR code.

## Note

- Il sito non richiede installazione, framework o compilazione.
- Il font viene caricato da Google Fonts; senza connessione resta un font di riserva.
- Il controllo audio è un promemoria visivo: non riproduce musica da solo. Puoi collegare una playlist o aggiungere un player.
- GitHub Pages pubblica normalmente il contenuto come sito pubblico: evita informazioni private o foto che non vuoi condividere pubblicamente.
