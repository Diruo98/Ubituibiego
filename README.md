# Tu & Io — Un universo, due anime 🌌

Un piccolo sito romantico, responsive e interattivo, pronto per GitHub Pages. Non richiede framework né compilazione.

## Personalizzalo prima di regalarlo

1. Apri `index.html` e cambia `TU & IO`, i testi e la firma finale.
2. In `script.js`, personalizza i testi dell'oggetto `memories` con i vostri ricordi.
3. Nella sezione “Le cose che custodisco” di `index.html`, sostituisci i testi segnaposto e, se vuoi, aggiungi vostre foto.
4. Puoi cambiare colori e stile in `style.css`. La palette principale è definita all'inizio in `:root`.
5. Per aggiungere una canzone, inserisci un link alla vostra playlist nella sezione colonna sonora. La versione iniziale non riproduce audio automaticamente.

## Pubblica gratis con GitHub Pages

1. Accedi a https://github.com e crea un nuovo repository, per esempio `tu-e-io`.
2. Carica `index.html`, `style.css`, `script.js` e `README.md` nella cartella principale del repository.
3. Apri **Settings → Pages**.
4. In **Build and deployment**, seleziona **Deploy from a branch**, scegli `main` e `/ (root)`, poi salva.
5. Dopo la pubblicazione, GitHub mostrerà l'indirizzo del sito nelle impostazioni Pages (di solito `https://TUONOME.github.io/tu-e-io/`).

## Crea il QR code

Quando il sito è online, copia l'URL pubblico e usa un generatore di QR code affidabile. Prova il codice con il telefono prima di stamparlo.

## Nota sulla privacy

Un sito GitHub Pages pubblico può essere visitato da chiunque abbia il link. Non caricare informazioni private o foto che non vuoi rendere pubbliche. Evita dati personali sensibili.
